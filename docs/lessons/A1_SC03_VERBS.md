# English Pro — A1 — Sous-chapitre 3 : Atelier spécial des verbes

**Version pédagogique 1.0 — brouillon à relire avant intégration.**  
**Objectif :** apprendre les verbes essentiels, leurs formes, leur prononciation et leur emploi en contexte.

Chaque leçon propose une explication, des exemples traduits, un quiz corrigé et une activité de pratique. Les verbes irréguliers sont mémorisés en phrases. Les enregistrements audio et la notation de prononciation ne seront annoncés hors ligne qu’après intégration et test réels.


## Leçon 01 — Comprendre ce qu’est un verbe

**Explication**  
Le verbe ou thème principal est **verb**. Son sens de base ici est **action**. Apprends-le dans la phrase et observe comment il fonctionne avec le sujet et le contexte. Certains verbes ont plusieurs sens ; la phrase aide à choisir la bonne traduction.

**Exemples anglais-français**  
Run is a verb. = Run est un verbe.

**Quiz**  
Which word is a verb?

- A. run
- B. blue
- C. table
- **Réponse correcte :** run
- **Correction expliquée :** Run exprime une action.
